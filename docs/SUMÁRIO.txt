 SEGURANÇA IMPLEMENTADA:

AUTENTICAÇÃO:
   ├─ Hash Bcrypt para senhas (impossível recuperar)
   ├─ password_verify() com proteção contra timing attacks
   ├─ Delay aleatório de 0.5-1.5s em falhas (anti-brute force)
   ├─ Sessões seguras com $_SESSION
   └─ Cookies HttpOnly + Secure + SameSite=Strict

VALIDAÇÃO:
   ├─ Email: FILTER_VALIDATE_EMAIL
   ├─ Telefone: regex para 10+ dígitos
   ├─ Nome: regex para letras/acentos/espaços
   ├─ Senha: mínimo 6 caracteres, máximo 128
   └─ Comprimento: range checks em todos campos

SANITIZAÇÃO:
   ├─ htmlspecialchars() com ENT_QUOTES
   ├─ Proteção contra XSS
   ├─ Suporte UTF-8 completo
   └─ Email normalizado com strtolower()

RATE LIMITING:
   ├─ 10 requisições por minuto por IP
   ├─ HTTP 429 (Too Many Requests)
   ├─ Auto-reset após timeout
   └─ Cache em /cache/rate_limit_*.txt

HEADERS DE SEGURANÇA:
   ├─ X-Content-Type-Options: nosniff
   ├─ X-Frame-Options: DENY
   ├─ X-XSS-Protection: 1; mode=block
   ├─ Strict-Transport-Security: (HTTPS)
   ├─ Referrer-Policy: strict-origin-when-cross-origin
   └─ Content-Security-Policy: default-src 'self'

LOGGING:
   ├─ /logs/auth.log - Eventos de autenticação
   ├─ /logs/agendamentos.log - Eventos de agendamento
   ├─ /logs/php_errors.log - Erros do servidor
   └─ Cada evento com timestamp + IP

PROTEÇÃO DE ARQUIVO:
   ├─ /dados_auth/usuarios.json - chmod 0600 (owner only)
   ├─ .htaccess - Rejeita acesso direto
   ├─ File locking - Evita corrupção
   └─ Diretórios criados automaticamente com modo 0755
